# MyPay BD — Full Non-Custodial Payment Gateway (Android App + Laravel 11 + Live Web Checkout)

## 1-Minute GitHub Auto-APK Build Instructions
1. Open [github.com/new](https://github.com/new) and create a new repository (e.g., `payguard-bd-gateway`).
2. Click **uploading an existing file**, drag and drop all extracted files/folders from this zip (`.github`, `app`, `laravel-backend`, `web-gateway`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`), and click **Commit changes**.
3. Click the **Actions** tab at the top of your repository — GitHub will automatically run **Build MyPay BD Android APK** and give you the downloadable **`MyPay-Installable-APK` (`app-debug.apk`)** in ~2 minutes!
